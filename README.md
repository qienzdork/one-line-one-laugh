# One Line, One Laugh

Entry for the [One Line, One Laugh](https://make.fun/c/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) competition on make.fun.

`main.py` (Python stdlib only) writes a single funny line to `/output/entry.txt`:

> I asked the barista for something strong. She handed me her resignation letter.

## Run

```sh
python3 main.py
```

The line is deterministic — the same 79 characters, byte for byte, on every run.
